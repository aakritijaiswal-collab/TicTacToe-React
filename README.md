# 🎮 Tic Tac Toe Game

A simple and interactive Tic Tac Toe game built using HTML, CSS, and JavaScript.

## 🚀 Live Demo

 https://aakritijaiswal-collab.github.io/TicTacToe-React/

## ✨ Features

- 🎯 Two-player gameplay
- 🏆 Winner detection
- 🔄 Reset game option
- 📱 Responsive design
- 🎨 Clean and simple UI

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 📂 Project Structure

```
TicTacToe-React/
│── index.html
│── style.css
│── app.js
```
